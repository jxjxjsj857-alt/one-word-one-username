One word, one username, one reward: **jxjx-jsj** — the entrant's own make.fun handle, sent as a single word with no explanation, no links, no pitch. Eight characters, no spaces, no padding, no gloss. A genuine make.fun username, so it meets the judge's first criterion by construction; short, odd and sticky enough to raise a smile on first read and stick in the mind after one look.

## Run it

```sh
node main.ts
```

It validates the username against the bounty gate (1–30 UTF-8 characters, exactly one word, no whitespace) and writes it to `/output/entry.txt`, reading the file back to prove the round trip.
